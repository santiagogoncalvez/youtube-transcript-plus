# yt-transcript-kit

Una librería ligera y eficiente en TypeScript para obtener y procesar transcripciones y metadatos de YouTube. Creada para desarrolladores que buscan datos fiables y una implementación limpia.

## Características

- **Procesamiento de transcripciones:** Segmentos limpios con códigos de tiempo.
- **Soporte de metadatos:** Incluye título, miniatura e ID del video.
- **TypeScript nativo:** Totalmente tipado para una mejor experiencia de desarrollo.
- **Universal:** Compatible con ESM y CJS.

## Instalación

```bash
pnpm add @santiagogoncalvez1/youtube-transcript-plus
```
